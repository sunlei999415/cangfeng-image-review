# 藏锋 sunlei520 图片生成项目（交接包）

> 用途：把当前需求、标准、已实现内容、样图与问题打包，便于线上 Gemini 或其他评审者独立阅读并给方案。
> 注意：**本包不含任何生产口令/API Key/SSH 私钥**；生产服务器地址与凭据已移除。

## 项目是什么
给电商/种草账号批量生成图片，三种模式：
- **融图（fusion）**：用客户给的场景图（Image 1），把商品换成图里的新产品（Image 2），保留原场景；
- **创品（creation）**：用 Image 1 的地点类型，重建同类型场景并放入 Image 2 商品；
- **生图（gen）**：只给商品，由模型生成新场景/新照片。

最终用于小红书/广场种草；要求“真实感 + 产品好看 + 大气 + 能一眼看到价格”。

## 评审建议
1. 先读 docs/对话要点与老板原话.md，理解老板的真实意图（真实=给人的感觉真实，不是素材真实）；
2. 再看 docs/图片标准_v2.md 与 samples/；
3. 按 docs/给线上Gemini的评审请求.md 逐条给方案；
4. 注意：Gemini 无法访问本机 staging/生产/API，只能给建议；执行与验证仍需本地完成。
