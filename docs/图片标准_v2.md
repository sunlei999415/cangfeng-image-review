# 图片标准 v2（2026-11-16 收敛，staging 验证用）

## 一、总标准（所有模式、所有品类）
1. **真实**：像真人手机在真实门店/场景拍的；无 AI 假感（塑料感、假反光、悬浮、假人、过度完美）。
2. **大气不 low**：干净留白、低饱和统一色、真实材质、陈列有序；没有杂物、廉价贴纸、爆炸贴、KT 板。
3. **产品是主角**：产品最大、最清晰、最亮（约 50-60% 画面）；场景/价格牌是陪衬。
4. **多品不克隆**：目标品 1-2 件做主角 + 其他不同款/色陪衬；禁止同款排/网格。
5. **场景适配**：场景匹配品牌档次/品类/价格（大牌不进仓库/地摊；平价不硬塞奢侈场景）。
6. **去同质化**：场景/机位/呈现/光线/道具/价格牌形式轮换；同批不出现近似构图。
7. **生图去重**：生图成品必须和产品参考图是不同拍摄瞬间（换角度/状态/场景/光），只保产品身份。

## 二、价格牌（LED 形式）
- 只用 **LED 屏**：自发光、黑边薄框；绝不 KT 板/纸板/印刷亚克力牌/桌面小屏。
- 形式轮换（按品类/场景）：
  - 服装门店：货架/龙门架上方吊挂 LED 屏、门店门头/橱窗 LED、商场柱子 LED；
  - 美妆：柜台 LED 屏、柜台上方吊挂屏、商场柱子 LED；
  - 包：货架上方吊挂屏、门店门头屏；
  - 礼盒：柜台 LED 屏、落地 LED 灯箱、柜台上方吊挂屏。
- **特写**：活动+价格块占画面约 25-35%，处于前景；价格数字最大（约画面高 1/9），150-200px 缩略图可读。
- 文字严格四行：品牌 / 品名 / 活动 / ¥价格；一图一牌；数字与订单数据一致；不得出现其他品牌、其他数字。

## 三、构图/质感
- 3/4 或正面稳定构图；产品清晰、材质/logo 可辨；自然店内光、真实反射/接触阴影。
- 价格屏要像真商场/门店里的屏幕（有吊挂支架/柱子/落地座），不是贴上去的。

## 四、验收
- 老板亲眼看图点头为准；不拿规则清单/识图报告代替看图。
- 未获明确“可以上线”，绝不动生产。
